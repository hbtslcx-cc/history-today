# History Today - UI设计图文档

## 设计概述

本文档提供 History Today APP 的完整UI设计图，包含所有页面的视觉设计、组件规范和交互说明。

---

## 1. 设计系统

### 1.1 色彩系统

#### 主色调
```
主色: #1e3a5f (深蓝色)
辅助色: #4a90d9 (亮蓝色)
强调色: #e74c3c (红色)
```

#### 功能色
```
宜(吉): #27ae60 (绿色)
忌(凶): #e74c3c (红色)
农历: #8b4513 (棕色)
今天标记: #e74c3c (红色)
选中: #1e3a5f (深蓝色)
```

#### 中性色
```
背景: #f8f9fa (浅灰白)
卡片: #ffffff (白色)
主文字: #333333 (深灰)
次文字: #666666 (中灰)
分割线: #e0e0e0 (浅灰)
禁用: #999999 (灰色)
```

### 1.2 字体系统

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 32sp | Bold | 40sp | 年月标题 |
| H1 | 24sp | Bold | 32sp | 页面标题 |
| H2 | 20sp | Medium | 28sp | 日期数字 |
| H3 | 18sp | Medium | 26sp | 农历日期 |
| Body | 16sp | Regular | 24sp | 正文 |
| Caption | 14sp | Regular | 20sp | 宜忌、节气 |
| Small | 12sp | Regular | 16sp | 星期、标签 |
| Tiny | 10sp | Regular | 14sp | 角标、提示 |

### 1.3 间距系统

| Token | 数值 | 用途 |
|-------|------|------|
| xs | 4dp | 图标间距、紧凑元素 |
| sm | 8dp | 元素间距、行内间距 |
| md | 12dp | 组件内部间距 |
| lg | 16dp | 卡片内边距、页面边距 |
| xl | 24dp | 模块间距 |
| xxl | 32dp | 大模块间距 |

### 1.4 圆角系统

| Token | 数值 | 用途 |
|-------|------|------|
| sm | 4dp | 小标签、按钮 |
| md | 8dp | 按钮、输入框 |
| lg | 12dp | 卡片 |
| xl | 16dp | 大卡片、对话框 |
| full | 50% | 圆形元素 |
